# Vision

## Product Vision

Project Hub is a documentation publishing platform designed to transform engineering
project knowledge into structured, reusable, and publicly accessible documentation.

The system allows project knowledge accumulated during learning, experimentation,
development, debugging, and project execution to be extracted, refined, organized, and
published through a personal website.

Instead of manually creating blog posts or webpages, users document projects within
Obsidian using markdown and supporting resources. Project Hub then converts this
documentation into a structured website suitable for learning, sharing, portfolio
building, and long-term knowledge preservation.

## Problem Statement

Engineering knowledge is often fragmented across:

- AI conversations (ChatGPT, Claude, Gemini, or any)
- Forums
- Screenshots
- Videos
- Project files
- Notes
- Personal observations

As projects grow, important decisions, mistakes, learnings, and discoveries become
difficult to locate and reuse. Most project work remains trapped inside conversations
rather than becoming structured knowledge assets.

## Vision Statement

Enable a completed project to move through the following workflow:

```
ChatGPT / Claude / Forums / Videos
→ Project Execution
→ Project Sealed
→ Knowledge Extraction
→ UPDS Documentation
→ Manual Refinement
→ Obsidian
→ Project Hub
→ Live Website
```

The final result should be a **searchable and shareable project documentation website**
that accurately captures the engineering journey behind each project.

## Version 0.1 Goal

Version 0.1 focuses on **validating the documentation publishing workflow**.

It is **NOT** intended to be:

- A community platform
- A project management platform
- A collaboration platform
- A social network
- A commercial SaaS product

Version 0.1 exists solely to prove that:

- Project knowledge can be documented efficiently.
- Documentation can be maintained inside Obsidian.
- Markdown documentation can be published automatically.
- A personal engineering knowledge website can be maintained with minimal effort.

## Expected Result

After completing this droplet:

- Product purpose is clearly defined.
- Product boundaries are clearly defined.
- The Version 0.1 objective is clearly defined.
- Future product discussions can be evaluated against the documented vision.
- Subsequent droplets can be created using a shared understanding of the product.
