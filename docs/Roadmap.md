# Roadmap

> Success criteria for Orbit 0.1 and the planned path beyond it.

## 1. Success Criteria

### 1.1 Minimum Outcome

- Repository established.
- Website deployed.
- Markdown pages rendered successfully.
- Basic navigation operational.

### 1.2 Target Outcome

- Obsidian-to-Website workflow operational.
- Project pages operational.
- Knowledge pages operational.
- Search functionality operational.
- Tags and categorization operational.

### 1.3 Stretch Outcome

- Automated publishing pipeline.
- AI-assisted documentation ingestion.
- Dynamic project dashboards.
- Foundation prepared for community features.

## 2. Bucket Roadmap (Orbit 0.1)

| Bucket | Focus | Status |
| --- | --- | --- |
| 0.1.1 – Product Definition | Vision, scope, workflow, requirements, success criteria. | ✅ Complete |
| 0.1.2 – Documentation Workflow | Extraction → refinement engine → manual refinement → Obsidian storage (PHDS). | ✅ Complete |
| 0.1.3 – Publishing Engine | Markdown → webpages; resources, links, metadata, content index, build. | ✅ Complete — frozen V0.1 baseline |
| 0.1.4 – Website Interface | Homepage, project/knowledge/portfolio pages, navigation. | ✅ Complete |
| 0.1.5 – Discovery System | Search, tags, categories, filtering, related content. | ✅ Complete — frozen V0.1 baseline |
| 0.1.6 – Deployment Pipeline | Obsidian → GitHub → Project Hub; automate and validate end-to-end. | ✅ Complete |

## 2.1 Orbit 0.2 — Planning (opens with the feedback loop)

Candidate directions, to be shaped by V0.1 usage (see [Vision Log](Project_Hub_Vision_Log.md)):

- Workflow feedback fixes and refinements from real publishing use
- Knowledge library growth (articles distilled from existing projects)
- Deferred re-entry points: callout admonitions, image optimization, custom 404, custom domain
- Early ecosystem steps: blog derivations, AI-assisted ingestion, richer related-content signals

## 3. Beyond Orbit 0.1 — Next Orbit Priorities

- Community Features
- User Accounts
- Collaboration Workspaces
- Project Sharing
- AI Knowledge Assistant
